Zova Support

Need a hand with Zova? Browse the topics below or email info.zova24@gmail.com.

Gemini API Key

Zova needs your own Gemini API key for live processing.

  • Create a key at Google AI Studio
  • Paste it into Zova Settings and save
  • The key is stored locally and never included in backups

Website Access

Chrome may ask you to allow access to a classroom or video site.

  • Choose "Allow" when prompted on the target page
  • Zova needs access to show Smart Class on that page

Starting Zova

  • Open the online lesson or video
  • Open Zova and choose your translation language
  • Press Start — Smart Class appears

Smart Class

  • Original text appears first, translation underneath
  • Resize, minimize or restore the Smart Class dock
  • Adjust text size and scroll inside the dock

Translation

  • Choose your target language before starting
  • Translation appears under the original text

Dubbing

  • Translated audio is optional and toggled separately
  • Turning it off does not stop Smart Class, transcript, Save Class or Auto-Save

Explain / Answer

  • Explain — a clearer explanation of a recent concept
  • Answer — a direct answer from recent context
  • These actions use recent classroom context and return the result inside Smart Class

Save Class

  • Use Save Class to keep the transcript, translations and Smart Notes
  • Saved classes stay in local Chrome storage

Dashboard

  • Open, search and review saved classes
  • Follow the Learning Map, Chapters and important class Vocabulary where available
  • Open focused Study Detail for a selected concept
  • Rename or delete classes, and export supported study material

Backup / Restore

  • Export Backup downloads your saved class data as JSON
  • Import Backup restores compatible saved classes
  • Your API key is never included in backups

Zova doesn't start?

Try these checks in order.

  • →Check that your Gemini API key is entered and saved
  • →Confirm website access is allowed for the page
  • →Reload the target page
  • →Reload the extension if necessary
