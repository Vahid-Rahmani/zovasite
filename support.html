Need help with Zova? Contact us by email.

Installation

Install Zova from the Chrome Web Store or load it as an unpacked extension.

Gemini API key

Open Settings, enter your own Google AI Studio Gemini API key and save it.

Website permission

Click Allow Website Access when starting on a classroom or video page.

Starting a class

Open a normal HTTP/HTTPS page with media, choose a mode and click Start.

Translation

Choose a target language before starting the session.

Saved Classes

Use Save Class or auto-save, then open Dashboard to review local history.

Backup / Import

Dashboard provides manual backup export and import. API keys are not included.
