Overview

Zova is an AI classroom assistant for Chrome. It provides user-initiated tab-audio transcription, translation, optional translated audio, classroom assistance and local lesson storage. This policy describes how Zova processes information when you use the extension.

Information Zova Processes

Depending on the features you use, Zova may process classroom tab audio, transcripts, translations, Smart Notes, saved classes, AI prompts and your Gemini API key.

Classroom Tab Audio

Classroom capture begins only after you press Start. Zova captures audio from the selected browser tab — not general computer audio — and processes it for the live features you request, such as transcription and translation.

Raw classroom audio is not intentionally persisted by Zova.

Transcripts and Translations

Generated transcripts and translations are displayed in Smart Class and may be saved locally when you save a class.

Google Gemini

When you start a session, user-initiated classroom audio and bounded classroom context are sent to Google Gemini to provide the requested live functionality. Google's terms and privacy policy apply to that processing.

Google AI Mode

When you explicitly choose Explain, Answer or Summary, Zova opens Google AI Mode and submits a bounded classroom-derived query. Your Gemini API key is not sent to Google AI Mode.

Gemini API Key

Your Gemini API key is stored locally in Chrome extension storage. It is not included in exported class backups.

Local Storage

Settings, transcripts, translations, Smart Notes and saved classes are stored locally using Chrome extension storage until you delete them or clear extension data.

Saved Classes

When you save a class, Zova stores the class metadata, transcript, translations, Smart Notes and supported study data locally on your device.

Backup and Export

Backups are created only when you manually request them. An exported backup contains saved class data and does not include your Gemini API key.

Website Access

Zova may request optional HTTP/HTTPS access when you start a mode that requires it, so it can display Smart Class and interact with the active classroom page.

Microphone Permission

Normal Smart Class uses selected-tab audio via tab capture, not your physical microphone. Physical microphone input is not the normal Smart Class audio source.

If microphone permission UI appears, it is used only for permission or compatibility checking and is not required as the audio source for Smart Class.

Data Sharing

Zova shares information with Google only when needed for a user-initiated feature. Zova does not sell user data and does not create advertising profiles.

Data Sale and Advertising

Zova does not sell user data. Zova does not use classroom data for personalized advertising.

Data Retention

Saved classes remain in local Chrome extension storage until you delete them or clear extension data. Remote retention of data sent to Google is governed by the applicable Google service terms.

User Control and Deletion

You can stop a session, delete saved classes, remove your API key from Settings, and avoid optional AI actions such as Explain, Answer and Summary.

Security

Zova limits API-key handling to its extension and API path, and excludes the key from exported backups.

Changes

We may update this policy when functionality or legal requirements change. Updates will be reflected on this page.

Contact

For privacy questions or support, contact Info.rivo24@gmail.com.

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
