Overview

Zova is an AI classroom assistant for Chrome. It provides user-initiated tab-audio transcription, translation, optional translated audio, classroom study tools, and local lesson storage.

Information Zova Processes

Depending on the features you activate, Zova may process selected-tab audio, transcripts, translations, Smart Notes, saved class metadata, classroom-derived AI prompts, and your user-provided Gemini API key.

Zova does not collect financial data, health data, location, browsing history, advertising identifiers, or screenshots.

Classroom Tab Audio

Audio capture begins only after you press Start. Zova captures audio from the user-selected browser tab using Chrome tab capture and streams it to Google Gemini for live processing. This is selected-tab audio, not physical microphone recording.

Raw classroom audio is not intentionally persisted as an audio file by Zova. Capture ends when you stop the session.

Transcripts and Translations

Gemini-generated transcripts and translations are shown during the session. Saved classes may include transcripts, translations, and Smart Notes, which may be stored locally in Chrome extension storage. Recent, bounded classroom context may be used for Explain and Answer when you explicitly invoke those features.

Google Gemini

Zova communicates with Google Gemini / the Generative Language API for live transcription, translation, optional dubbing, and bounded AI processing where applicable. Google's own terms and privacy policies apply to processing performed by Google services. Zova does not claim a specific Google retention period.

Background AI Assistance

When you explicitly select Explain or Answer, Zova processes a bounded classroom-derived request through its approved background assistant flow and returns the result to the learning interface. Zova does not send your Gemini API key through that assistant flow and does not currently store assistant response text as saved class history.

Gemini API Key

You provide your own Gemini API key. It is stored locally in Chrome extension storage and used to authenticate requests to Google's Generative Language API. It is not included in exported class backup files, is not intentionally exposed to ordinary webpages, and is not sent through the background assistant flow.

Local Storage

Zova uses Chrome extension storage. Persistent local data may include settings, the Gemini API key, saved classes, transcripts, translations, Smart Notes, usage preferences, and Dashboard display preferences. Temporary session state may include active session metadata and classroom state.

Saved Classes

Saved classes can contain class metadata, transcript entries, translations, Smart Notes, and a Clean Study File when available. They remain in local Chrome extension storage until you delete them or clear extension data.

Backup and Export

You can manually export saved class data. A backup may contain classes, transcripts, translations, Smart Notes, Clean Study Files, and class metadata. The Gemini API key is not included. Zova does not perform automatic cloud backups.

Website Access

Zova may request optional access to HTTP/HTTPS classroom or video pages when needed for Smart Class and selected-tab functionality. This access relates to user-selected classroom or video pages and does not mean Zova collects browsing history.

Microphone Permission

Normal Smart Class uses selected-tab audio through Chrome tabCapture. Physical microphone audio is not the normal Smart Class audio source. If the Settings page requests a microphone permission check, a temporary permission-test stream may be requested and its tracks are stopped immediately after the test. Physical microphone audio is not sent remotely by the normal Smart Class pipeline.

Data Sharing

Zova shares data with Google services only when necessary for user-requested functionality, such as Gemini processing or approved background assistant actions. Zova does not intentionally share classroom data with advertising networks or unrelated third parties.

Data Sale and Advertising

Zova does not sell user data, use classroom data for personalized advertising, create advertising profiles, or use or transfer user data for creditworthiness or lending decisions.

Data Retention

Saved classes remain in local Chrome extension storage until deleted by you or removed through browser or extension storage controls. Remote retention by Google services is governed by Google's applicable terms and policies.

User Control and Deletion

You can stop an active session, delete saved classes, clear extension data, remove or change your Gemini API key, avoid optional AI features, and export or restore class backups.

Security

No production API key is hardcoded in the extension. Your API key is stored locally and excluded from class backups. Extension JavaScript is packaged with the extension; remote executable JavaScript is not downloaded or executed. Gemini network communication uses HTTPS/WSS.

Changes to This Privacy Policy

This Privacy Policy may be updated when Zova functionality or legal requirements change. The effective date will be updated accordingly.

Contact

For privacy questions, contact Vahid Rahmani at info.zova24@gmail.com. You can also visit the Support page.

Zova's use of information received from Google APIs is limited to providing and improving the user-facing functionality requested by the user and follows applicable Chrome Web Store User Data Policy requirements.
