Privacy, by design

Your lessons stay in your hands.

Zova starts capture only when you press Start, processes the selected tab for the features you request, and keeps your saved lessons local.

  • Raw classroom audio is not intentionally persisted

Questions

Frequently asked questions

What is Zova?
Zova is an AI-powered Chrome extension that helps you follow online lessons with live transcription, translation, optional translated audio, focused classroom assistance and locally saved study notes.
Do I need a Gemini API key?
Yes. Zova uses a user-provided Gemini API key for Gemini-powered live processing. You create the key in Google AI Studio and paste it into Zova Settings.
Where are my classes stored?
Saved classes are stored locally in Chrome extension storage on your device — not on a Zova server.
Does Zova record my microphone?
No. Normal Smart Class uses selected-tab audio via tab capture, not your physical microphone. Microphone permission may appear only for compatibility or verification purposes.
Does Zova save raw classroom audio?
No. Raw classroom audio is not intentionally persisted by Zova. It is processed for the live features you request.
Can I turn Dubbing off?
Yes. Translated audio is optional and can be enabled or disabled separately from Smart Class and class saving.
Does Save Class work without Dubbing?
Yes. Turning Dubbing off does not prevent Smart Class, the transcript, Save Class or Auto-Save.
What happens when I click Explain?
Zova processes recent educational classroom context in the background and returns a focused explanation inside Smart Class.
What happens when I click Answer?
Zova uses the latest relevant classroom question and bounded context to return a concise, direct answer inside Smart Class.
What is the Learning Map?
It organizes the saved class into meaningful Chapters, Topics and Concepts rather than creating one study item for every spoken sentence.
What is Study Detail?
Study Detail is a focused learning unit for a selected Topic or Concept, reviewed progressively with useful sections when relevant.
Does Zova turn every spoken sentence into a study item?
No. Zova identifies meaningful educational structure from the class instead of making one learning node for every spoken sentence.
Are my saved classes uploaded to a Zova server?
No. Saved classes remain in local Chrome extension storage.
Does backup contain my API key?
No. Your Gemini API key is never included in exported class backups.
Can I restore my classes?
Yes. Use Import Backup to restore compatible saved classes from a previously exported backup file.
Is Zova available in the Chrome Web Store?
Yes. You can install Zova directly from the Chrome Web Store.
