Privacy, by design

Your lessons stay
in your hands.

Zova starts classroom capture only after you start a session. Classroom tab audio is processed for the requested AI functionality, while saved classes remain in local Chrome storage.

Your Gemini API key is stored locally and is not included in class backups. Zova does not sell user data or use classroom data for advertising.
